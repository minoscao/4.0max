Use case: ui-mockup
Asset type: premium responsive desktop web dashboard mockup for an Industrial 4.0 maintenance administrator in Malaysia
Primary request: Create a completely new visual direction for the administrator dashboard. It must look like a sophisticated contemporary operations control console used by a premium airport or logistics network, not a generic Chinese government-enterprise dashboard, not a traditional ERP, and not a colorful data wall.

Design thesis: maintenance calls are live operational movements on one shared timeline, not isolated statistic cards. The interface should feel precise, calm, expensive, internationally credible, and product-specific.

Scene and users: Malaysian factory maintenance manager using a large PC display during a 12-hour shift. The interface must remain practical and readable under normal factory office lighting.

Style/medium: shippable high-end product UI, sharp editorial composition, modern neo-grotesk Chinese typography, tabular numerals, refined hairline dividers, disciplined spacing. Predominantly flat surfaces with depth only where function requires it. No illustrations and no decorative dashboard icons.

Color system:
- cool porcelain background, not warm beige
- graphite black ink
- mineral navy as the structural color
- one electric lime accent only for healthy/available state
- one burnt orange accent only for actions and operational exceptions
- no large teal sidebar
- no primary blue gradient
- no red alarm wall

Composition, 16:9 full browser viewport, no device frame:
- A very narrow 72px graphite navigation rail on the far left with refined line icons; a slim adjacent text menu column on porcelain ground, not a colored block.
- A quiet top utility bar with factory/shift context, role switch, language selector, notifications, and avatar.
- Main canvas is one continuous editorial field divided by hairlines, not a collection of rounded cards.
- Page header on the left: “管理总览” and one small contextual line.
- Top metrics appear as one horizontal instrument strip separated by vertical rules, never as four cards.
- Main hero area is asymmetrical: left 40% is an operational exception queue; right 60% is a large horizontal downtime timeline covering the shift.
- Bottom area is split into a flat machine-risk ledger and a technician-capacity strip. No boxed card shadows.
- Use small 6–10px corner radii only where controls need them. Pills only for status tags and compact role/language switches.
